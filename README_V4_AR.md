# إعداد v4 — اختيار نماذج الصور تلقائيًا

1. ارفع محتويات مجلد `assets` إلى مستودع GitHub نفسه الذي يتصل به تطبيق Streamlit، مع الحفاظ على الملفات في مكانها.
2. في Streamlit Cloud افتح التطبيق ثم Settings → Secrets.
3. اترك `GEMINI_API_KEY` كما هو إذا كان المفتاح الحالي صحيحًا وسريًا. لا تضع المفتاح في GitHub.
4. اختياريًا أضف ترتيب النماذج التالي، ويمكن تعديل الترتيب لاحقًا:

```toml
GEMINI_IMAGE_MODELS = "gemini-3-pro-image-preview,gemini-3.1-flash-image-preview,gemini-2.5-flash-image"
```

5. احفظ Secrets ثم أعد تشغيل التطبيق. سيظهر العنوان v4.
6. عند فشل نموذج بسبب 429 أو عدم توفره، يحاول النظام البديل التالي. إذا فشل أي مشهد بعد تجربة كل البدائل، يوقف إخراج الفيديو حتى لا يستبدل المشهد بأشكال قديمة.

مهم: تأكد من معرّفات النماذج المتاحة فعليًا لحسابك في توثيق Google قبل استخدامها؛ أسماء النماذج قد تتغير. هذا التعديل لا يضمن تجاوز الحصص ولا يجعل النماذج المدفوعة مجانية.
