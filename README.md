# 🎬 استوديو أتمتة المونتاج وصناعة الموشن جرافيك الذكي (سحابي + محلي)
# (AI Video Automation, Algerian Darija & Studio Motion Graphics System)

نظام هجين متكامل يعمل عبر الإنترنت (السحابة) أو محلياً لتحرير الفيديوهات والملفات الصوتية وصناعة الموشن جرافيك الاحترافي بالذكاء الاصطناعي، مع دعم مخصص للدارجة الجزائرية 🇩🇿 واللغة العربية:

- **حل شامل لرفع الملفات والتسجيلات الصوتية:** يدعم جميع صيغ الصوت والفيديو (`mp3, wav, m4a, ogg, opus, aac, amr, webm, 3gp, mp4, mov, mkv...`) مع التحويل التلقائي الفوري وميزة التسجيل الصوتي المباشر من المايكروفون داخل الموقع.
- **فهم متقدم للدارجة الجزائرية (Algerian Darija):** موجهات صوتية مخصصة في Whisper + قاموس لهجة جزائرية + تدقيق سياقي بالذكاء الاصطناعي مع الحفاظ التام على التوقيت الزمني.
- **النمط التلقائي الذكي ودمج كل الأدوار (Smart Director All-in-One):** يحلل خصائص الصوت والفيديو (شدة الصوت dBFS، الضجيج، نسبة الصمت، حركة الكاميرا، وسرعة الإلقاء) ليحدد أفضل الإعدادات والموديلات تلقائياً ويدمج كل الأدوار البصرية بمعايير علمية.
- **نمط دمج الموشن جرافيك بالفيديو الأصلي:** تراكب بطاقات الأنفوجرافيك الزجاجية والأيقونات الفيكتور الديناميكية والكابشن التفاعلي مباشرة فوق الفيديو الأصلي للمتحدث.
