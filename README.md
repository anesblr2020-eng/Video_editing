- **مسار بصري هجين:** تخطيط مشاهد دلالي، وتوليد صور عند توفر المزود والحصة، وتخزين مؤقت للصور، ورندر يجمع الصور مع الرسومات المتجهية. وجود وصف للمشهد لا يعني أن صورة مولدة متوفرة دائماً.
- **التشخيص الصريح:** تُسجّل حالات فشل توليد الصور. عند غياب صورة صالحة، يستخدم الرندر رسماً توضيحياً سياقياً محلياً بدلاً من ادعاء نجاح التوليد. هذا الرسم الاحتياطي ليس مكافئاً لصورة سينمائية أو مجسم ثلاثي الأبعاد احترافي؛ راجع `V8_WORK_BOARD_AR.md` لمعرفة الحدود.

- **معالجة الصوت والمشاهد:** أدوات لتقسيم المشاهد وقص الصمت مع محاولة الحفاظ على إيقاع الكلام الطبيعي؛ النتيجة تعتمد على جودة الصوت والتفريغ والإعدادات.
